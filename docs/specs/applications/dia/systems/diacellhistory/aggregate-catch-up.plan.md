## Implementation Patterns

- **Request parsing (task 1):** extend `NormaliseArgs`/`Aggregates` with the existing `ParseUInt` helper; errors through `Fail(kAggName, msg)` with `snprintf` into the local `err` buffer, naming the reason. Update `kParamsAgg` `ValueParam`s (`groups` array, `stride` int, `layerOffset` int) and the `Help(...)` text (AC 14). Keep header comment block at the top of `HistoryQueries.h` in sync.
- **Groups filter (task 2):** a group-selection mask analogous to `wanted`, resolved by group id string against `rec.Aggregates().GroupAt`; passed into `Rows::CollectAggLayers`/`BuildAggregateBody` as an optional `const std::vector<bool>*` (null = all, so the topic and exporter are unchanged). `groupSizes` filtered by the same mask.
- **Layer slicing (task 3):** mirror `Cells()`: when `FitCount` returns 0 for a whole sample, switch to a one-sample reply and size a layer count with the same `FitCount` helper over `build`'s layer slice; `next = { from, layerOffset }` when layers remain, `{ from + n, 0 }` when the sample is complete. A request with `layerOffset > 0` returns the rest of that one sample only. Cursor also carries `structure` (checked against `StructureHash()`) and echoes `groups`/`layers`/`stride` only through the request (stateless server, per the header comment: "a cursor in `next` carries everything").
- **Stride (task 4):** pure function in a new `HistoryStride.h/.cpp` (or inside `HistoryRows`) with no recorder dependency beyond input spans: `MinOfMins`, `MaxOfMaxes`, group-size-weighted mean; category layers copy the last sample's counts. PD-004: no STL in the public header (DiaCore types), implementation may use scratch buffers. Window alignment relative to `from`; partial last window included; `samples[i]` from the window's last sample; `groupSizes` from the window's last sample.
- **Observation:** extend `QueryObservation` with a counter for sliced replies and strided requests; no new sim-hosted names.
- **Tests:** `Dia/DiaCellHistory/Testing/` fixtures (`HistoryTestRig.h`), `SetMaxReplyBytes` seam for slice boundaries, reference computation for stride written independently in the test.
