Stages Tab — Static Mode

Linear stage graph laid out left-to-right in manifest array order. Solid arrows are auto-advance edges (drawn only between adjacent pairs where the source stage is in auto_stages). The initial stage is highlighted with a green ring. Manual stages are visual terminals — runtime transitions to them happen via DiaAPI transition_to, not through the graph. The graph is read-only; stage edits remain in the sidebar (StageConfiguration).
