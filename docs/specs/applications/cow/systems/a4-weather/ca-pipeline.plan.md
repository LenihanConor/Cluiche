## Deltas from the old plan (Feature 1's real shape)

- **No baseline provider.** `IBiomeSeasonalBaseline` is gone. The 13-entry baseline table is `params.BaselineRow(season)` (already in the snapshotted `WeatherParameters`), or the optional per-cell `SeasonalBaselineInput` when A1 supplies it. `Capture` latches a **per-cell seasonal baseline array** (`seasonBaseline[c]`, computed at `Capture` from the row by `biome[c]`, with `BiomeRegistry::ResolveOrFallback`, `kNoBiome` = 0.5), so `Run` never sees the registry or the params table. AC 1/2 poison the `SeasonalBaselineInput`, the `WeatherParameters` object and the forcing list after `Capture`.
- **`Capture` signature:** `Capture(const WeatherParameters&, Season, uint32_t weekOfYear, const BiomeRegistry&, const SeasonalBaselineInput*, const HydrologyInputs&, const InfluenceSnapshot&)`. `Step` takes the same plus the executor. `SeasonalTargetTemperature` (Feature 1) is the pass 1 target helper.
- **`InfluenceSnapshot`** is Feature 7's type. This feature adds a minimal empty placeholder in `WeatherTypes.h` (`struct InfluenceSnapshot { bool IsEmpty() const; }`, always empty here) so pass 0 is "skipped when empty" and Feature 7 fills it. Likewise per-cell `ClimateOffsets` (`tempOffset`, `evapMultiplier`, `windShift`) are latched at `Capture` as zero/one/zero defaults; Feature 8 fills them.
- **`HydrologyInputs`** already carries `glacierCheckWeek`, `glacierSnowFloor`, `present`. Use them as is.
- **Westerly band and `orographicFactor`** (open item 9): S-1 is in `DraoiHexWorldTerrain`, which this package does not depend on. Decision: add `WesterlyBand { float lat1 = 1/3, lat2 = 2/3 }`-style latched struct and optional per-cell `orographicFactor` (default 1.0) to a small `WeatherPipelineInputs` set by the caller before `Capture` (setters on `WeatherSimulation`, latched at `Capture`). Task 0 reads the current constants in the GDD `A4_TechnicalSpec.md` §5 and S-1's parameters to fix the default band values so output equals the GDD 30/60 degree behaviour; the application wires S-1's values later.
- **Test parameters** are hand-built (`MakeTestParams()` sets every field a pass reads to the GDD §14 defaults). Draoi tests never load the CoW sidecar.
- **AC 33 (deferred vs synchronous)** needs DiaDeferredStep's manual launcher; DiaDeferredStep is Done (2026-11-18) but Draoi must not depend on it. Re-homed: the test lives in the application (CoW) at Feature 3 (`WeatherStep`); this plan marks AC 33 `Moved to Feature 3` and drops row 21. A synchronous `Capture; Run; Commit` equals `Step` stays here (AC 5).

## Implementation patterns (unchanged design, condensed)

Spec sections "Lifecycle", "Grid tables", "Stable reads", "The pipeline", "Wind snap", "Transport gather", "Forcings", "Grid totals", "Profile" and the gap-pass and world-sim amendments are the contract; the points below are reminders.

- `Run` takes only latched state: `CapturedInputs` (params copy, season, weekOfYear, per-cell `seasonBaseline`, westerly band, `orographicFactor`, forcing copy, cell-set copy, `HydrologyInputs` copy, `InfluenceSnapshot` copy, `ClimateOffsets`, biome-edit copy if any), the immutable terrain, grid tables and scratch. **No heap allocation in `Run`**: every scratch array, table and cell-set storage is sized at `Initialise` (`BuildGridTables()` seam) and reused; AC 6 asserts data pointers and capacities unchanged across `Run`. `DynamicArray` does not grow on `Add`; `Assign`/`operator=`/`Swap` truncate to destination capacity (Feature 1 gotcha): `Reserve` then fill, and size working/committed fields identically.
- Neighbour table `neighbours[N*6]` from `Dia::Geometry2D::HexTopology::NeighbourAt`, `kNoCell` off-edge; unit vectors for `d = 0..5` at `30 deg + 60 deg * d`, ccw, y-down. Scratch: `moistureOut`, `heatOut`, `anomalyOut`, `dirIndex` (`uint8_t`), pass 0's per-cell deltas.
- One `ParallelFor(N, kMinRange = 256, fn)` per pass, `DIA_PROFILE_SCOPE` per pass. Stable-reads rule: no pass reads from a neighbour a field it writes. Transport is gather with fixed direction-order summation and edge term last.
- Profile has 14 entries (0, 1, 2, 3, 4, 5a, 5b, 5c, 6a, 6b, 7, 8, 9, finish); pass 10 retired.
- `RouteCondensate(cell, amount)` helper shared by orographic and pass 8.
- Biomes are `BiomeIndex` only; the pipeline holds no biome constant.
- Forcings: POD record, 64 records, 16 cell sets, lowest record index wins per cell and kind (per-kind bitset allocated at `Initialise`); wind override `value` radians, `value2` speed, `weeksRemaining` 0 = until cleared; `ClearForcings()` is Feature 6's, `ClearCellSets()` drops dependent forcings.

## Speed-ups

- 30 rows merged to 14: passes grouped in the order they share helpers and test fixtures (rows 6-9, 10-12, 13-15 were already commit-grouped).
- Per-task verification is one scoped `dia run googletest --filter="Weather*" --shards 2` build (the whole Weather prefix is small, 66 tests plus new), which also covers earlier tasks as a regression. Determinism matrix (52 weeks, Large) runs once, in the determinism task.
- No mutation checks, no sanitizer, no Release benchmarking, no `SLOW_` suites. One feature-wide scoped run at the close-out; the full unfiltered suite is Phase 4 only.
- Docs and plan updates are batched into the commit of the task they track.
