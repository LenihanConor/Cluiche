## Implementation Patterns

Decisions made at plan time; check against the real code before marking tasks Done.

**Storage.** `WorldStructure` (TerrainTypes.h) gains `RegionTable regions; SiteSet sites;` and `Cell` gains `RegionId region = 0`. Existing precedent: `WorldStructure` keeps cells in a private `std::vector` behind a pointer/count API (PD-004 deviation already noted in the backlog). `RegionTable`/`SiteSet` may do the same internally with a pointer/span public API; avoid `std::` containers in public signatures. Cell is memset+memcpy'd and compared bytewise: `RegionId` is `uint8_t`, put it where padding is deterministic and re-check the Cell golden hashes (regenerate deliberately and list them).

**Freshness.** Regions and sites are computed on Regenerate only (SD-S1-004). Any terrain or biome revision change from live preview clears them (all `Cell::region` = 0, empty table and sites) and sets `regionsFresh=false` in status, until the next Regenerate. Confirm with the user at task 8 if the panel needs them to persist across slider moves.

**Sub-seeds.** `DeriveSubSeed(uint64_t parent, StringCRC step)` = splitmix64 finaliser of `parent ^ (uint64_t(step.Value()) * 0x9E3779B97F4A7C15)` (any fixed mix is fine; it must be deterministic and well spread). Provide two overloads: `DeriveSubSeed(uint64_t parent, StringCRC step)` and `DeriveSubSeed(uint64_t parent, uint64_t key)` (same mixer; the CRC overload feeds `step.Value()`). Attempt seed = `DeriveSubSeed(outer, uint64_t(attempt))`; each step seed = `DeriveSubSeed(attemptSeed, stepId)`. Step ids: "CoW.Regions", "CoW.Node.Corridor", "CoW.Node.River", "CoW.Node.Fill", then each registered kind's id. Reseed the passed `RandomStream` with `Restore(foldedSeed, 0)` as `RunSeedFields` does (`FoldSeed` in TerrainGenerator.h). Use the WLD stream passed in; do not create new streams.

**Registry order.** Topological sort (dependencies first); ties by registration order; cycle or duplicate kind rejected by `Register` (false, registry unchanged); cached order invalidated by any Register/Unregister; unregistering a kind that others depend on is allowed but they then have a missing dependency: treat as an error from `Register` only (unregister never fails), and `Order()` skips unmet dependencies' absence silently (document in a test).

**Region partition (spec "Region partition").** Tie-breaks: lowest cell index, then lowest region id. Dijkstra heap key `(cost, cellIndex, regionId)` with a deterministic comparator; costs are floats from the rules, accumulate in fixed order. Cap handling: a capped region stops being a source; leftovers go to the cheapest adjacent region ignoring the cap, processed in ascending cell index until none left (iterate until no change). First seed per component: `component[rng.RandomInt() % size]` after sorting cells by index (a single stream draw); farthest-point sampling ties: lowest cell index. Repair order: split pieces (largest piece keeps; ties lowest min cell index), then undersized merges in ascending region size then id, then absorption counting, then renumber by smallest cell index. Neighbour lists sorted ascending.

**Corridors.** Barrier-1 candidates: land cells at the First Shores/Wild Reaches boundary (a cell of one zone with a hex neighbour in the other); barrier 2 likewise Wild Reaches/Ancient Interiors. Candidate sources: `Pass` flag, `RiverCrossesBarrier`, coastal gap (no Ridge/Barrier flag within 2 steps, within `kCoastalGapReach` of a coast cell). Candidate list is sorted by cell index then a Fisher-Yates shuffle with the step stream; stable-partition so passes and rivers precede coastal gaps. Widths: pass = 1 node; river/coastal = accepted cell + up to 2 neighbouring boundary cells of the same source (lowest index first). `flags` bit0..1 barrier (1|2), bit2..3 source (0 pass, 1 river, 2 coastal), bit4..5 width-1; `variant` = corridor ordinal within the barrier.

**River nodes.** Per river tree (rivers are the `River` waterSource cells following `Cell::downstream`): mouth = river cell whose downstream neighbour is ocean or lake; walk the longest upstream path (ties lowest cell index) and place a node every `kRiverNodeSpacing`. Island rivers: mouth only. A river node on a `RiverCrossesBarrier` cell may coexist with a corridor node on that cell (spacing waived).

**Fill.** Quota per spec; slot order is region id then slot index; per slot the stream draws (1) kind draw then (2) weighted cell draw with weights from the yield table (Food/Materials High 3, Medium 2, Low 1) in the spec; cells iterate in ascending index so the weighted pick is deterministic. Spacing check uses a precomputed node distance mask updated after each placement.

**Layout check.** `CheckLayout(const WorldStructure&, const Rules&) -> LayoutReport { ok; violations[] {code, cells[], region, count} }` covering the 5 numbered checks in the spec's Layout guarantee section; evidence lists cell indices (capped, e.g. first 16) and counts. Task 13 wraps this as `IWorldGuarantee`.

**Test helpers in `Testing/`.** `RegionTestWorlds.h` (hand-built worlds for AC8 violations and for barriers with/without passes, rivers, coastal gaps), `TestPlacers.h` (placers A, B depends on A, C independent; a placer that returns retryable/terrainCause; a failing test guarantee is task 14's), `RegionChecks.h` (region validity helpers shared with the dragon layer: partition, connectivity, zone purity, neighbours symmetric).

**Build wiring.** `dia docs vcxproj-add CoW "Shared\WorldGeneration\X.h" --filter Shared` (+ .cpp); `dia docs vcxproj-add GoogleTests "..\..\CoW\Shared\WorldGeneration\X.cpp"` per new Shared .cpp and `dia docs vcxproj-add GoogleTests "CoW\TestX.cpp"`; PowerShell or literal paths only; check both `.filters` for a bogus `..` folder. Scoped runs: `dia run googletest --filter="*Region*:*Site*:*Biome*:*Terrain*:*WorldGen*" --shards 2`; one full run only in the last task.

**Test tiers.** Default run: hand-built cases, golden region arrays for fixed seeds, cheap seed subset (3 seeds x default + 3 presets). 20/100-seed sweeps in `SLOW_` suites. AC5/AC7/AC8b distribution items are tuning-gated: if a threshold fails, report numbers, do not tune (tuning is at the visual gate, task 10).
