COMMANDS THIS PANEL ASSUMES
EXISTSregenerate, cancel, export {name, overwrite}, import {name}, report, status (state, locked, source, generating, progress{attempts, maxAttempts, elapsedSeconds, timeoutSeconds}, layout, generation{outcome, message, attempts}), regions, sites, cell, layers {layer:"regions"}, view toggle of regions.edges, sites, sites.<kind>, view.siteKinds.
GAPNo cow.worldgen.validate command. The validator is a library call; the Validate button needs a command (runs the registered guarantees on the current world and returns the full ValidationResult).
GAPreport.finalValidation is thin: guarantee ids are CRC numbers (no names) and only counts of diagnostics and violating cells. The rows here need names, diagnostic text, violating cell indices, proof-path count and measurements.
GAPNo world-file listing. The import list needs a cow.worldgen.worlds query (names, size, modified time, which directory) over the out and deployed worlds directories.
GAPImport error shape: the reply has field and an error message; there is no line/column. The box shows what exists.
GAPEvidence overlay needs a drawer that reads the last ValidationResult (violating cells, proof paths) from the session. No such drawer or snapshot yet.
GAPStatus has no per-layer availability after an import (only derivable layers are rebuilt). The layer picker needs layers summary to flag unavailable layers.
GAPCell reply: sites at the cell, region and zone exist; "fragment / absorbed" flag per cell does not (only world totals in regions). Shown as optional.
